# Sportik — персональный трекер тренировок (Telegram Mini App)

Программы и блоки периодизации, импорт из Excel/CSV, проведение тренировки с таймерами,
адаптивные рекомендации по нагрузке, календарь, статистика, история веса.

## Запуск локально

```bash
npm install
cp .env.example .env      # ALLOW_DEV_AUTH=1 — вход без Telegram
npm run dev               # API на :8787, интерфейс на http://localhost:5173
```

```bash
npm test                  # unit-тесты: импорт, AdaptiveLoadEngine, расписание, тренировка, сервер
npm run typecheck
```

## Подключение к Telegram

1. В [@BotFather](https://t.me/BotFather) создайте бота (`/newbot`) и скопируйте токен в `.env` → `BOT_TOKEN=...`.
   Для продакшена поставьте `ALLOW_DEV_AUTH=0`.
2. Приложению нужен публичный HTTPS-адрес:
   - для теста — туннель на локальную машину: `npm run build && npm start`, затем
     `cloudflared tunnel --url http://localhost:8787` (выдаст адрес `https://….trycloudflare.com`);
   - постоянно — любой хостинг с Node 24+ и диском (VPS, Railway, Fly.io): `npm ci && npm run build && npm start`.
     База — один файл SQLite (`DB_PATH`), его нужно хранить на постоянном диске и бэкапить.
3. В BotFather: `/mybots` → бот → *Bot Settings* → *Menu Button* (или `/newapp`) → вставьте HTTPS-адрес.
4. Откройте бота в Telegram и нажмите кнопку меню.

Сервер проверяет подпись `initData` каждого запроса токеном бота, данные каждого пользователя Telegram хранятся отдельно.

## Архитектура

```
server/            Node + Hono + SQLite (node:sqlite)
  index.ts         API: POST /api/sync, раздача собранного клиента
  db.ts            хранилище документов, last-write-wins по updatedAt, курсор seq
  auth.ts          проверка Telegram initData (HMAC)
src/
  domain/          бизнес-логика без UI и хранения
    types.ts         модель данных
    adaptiveLoad.ts  AdaptiveLoadEngine
    workout.ts       операции над тренировкой (чистые функции), таймеры по меткам времени
    schedule.ts      последовательность программы, календарь
    stats.ts         статистика
    exerciseLibrary.ts  библиотека упражнений, сопоставление названий
  import/          parseTable.ts (распознавание таблицы), buildProgram.ts (черновик → программа), readFile.ts (SheetJS)
  data/            db.ts (IndexedDB + очередь outbox), store.ts (память + React-хуки), sync.ts, repo.ts (операции приложения)
  ui/              экраны и компоненты
  telegram/tg.ts   обёртка Telegram.WebApp (тема, haptics, BackButton), no-op в браузере
docs/excel-import-analysis.md  разбор формата программы и схема импорта
```

**Данные.** Каждое изменение сначала пишется в IndexedDB вместе с записью в очередь отправки (одна транзакция),
затем очередь отправляется на сервер (с задержкой и повторами при ошибках). Поэтому тренировка не теряется
при обновлении страницы, сворачивании Telegram или пропаже сети; индикатор синхронизации показывает состояние.
Повторная отправка одного и того же подхода безопасна: сервер принимает только более новую версию документа.

**Тренировка хранит снимок** названия и назначения каждого упражнения, поэтому изменение или удаление
программы не меняет историю. Замена упражнения во время тренировки не трогает программу.

**AdaptiveLoadEngine** сравнивает фактический RIR с целевым RIR упражнения (из интенсивности блока:
лёгкая 5–6, средняя 3–4, тяжёлая 0–1; по умолчанию 1–2) и предлагает увеличить, оставить или снизить вес
с объяснением. Решение принимает пользователь; принятый вес подставляется в следующую тренировку.
