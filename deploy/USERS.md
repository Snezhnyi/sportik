# Как дать доступ к Sportik новому человеку

Приложение приватное: пользоваться им могут только Telegram-аккаунты из списка
`ALLOWED_USER_IDS` в `/opt/sportik/.env`. Остальные видят экран «🔒 Доступ закрыт».

Управлять списком удобнее скриптом `deploy/users.sh`.

## Добавить пользователя

**1. Узнайте его Telegram ID** (число, не @username). Любой способ:

- Человек открывает вашего бота и нажимает кнопку приложения. Он увидит «Доступ закрыт»
  и кнопку `ID: 123456789` — нажатие копирует ID, он присылает его вам.
- Или после его попытки входа посмотрите ID в логе сервера (шаг 2, команда `list`).
- Или он пишет боту [@userinfobot](https://t.me/userinfobot) — тот ответит его ID.

**2. Зайдите на сервер:**

```bash
ssh root@188.120.239.157
cd /opt/sportik
```

**3. Посмотрите текущий список и последние попытки входа:**

```bash
sh deploy/users.sh list
```

Пример вывода:

```
Разрешённые пользователи:
  858820475

Последние входы (с момента запуска контейнера):
  allowed Telegram user id=858820475 name="mike" username=Livsii214
  DENIED Telegram user id=123456789 name="Иван" username=ivan
```

`DENIED` — тот, кто пытался войти без доступа. Его ID — число после `id=`.

**4. Добавьте:**

```bash
sh deploy/users.sh add 123456789
```

Можно сразу несколько: `sh deploy/users.sh add 123456789 987654321`.
Скрипт сам перезапустит приложение (около 5 секунд). Человек закрывает и снова открывает
приложение в Telegram — доступ есть.

## Убрать доступ

```bash
sh deploy/users.sh remove 123456789
```

Данные этого человека остаются в базе, но он их больше не видит. Если вернуть его в список —
всё снова на месте.

Скрипт не даст удалить последнего пользователя: пустой список означает «вход для всех».

## Без скрипта (вручную)

```bash
nano /opt/sportik/.env
```

Строка со списком, ID через запятую, без пробелов:

```
ALLOWED_USER_IDS=858820475,123456789
```

Сохранить (`Ctrl+O`, Enter, `Ctrl+X`) и применить:

```bash
cd /opt/sportik && docker compose up -d app
```

## Важно

- **Пустой `ALLOWED_USER_IDS=` — вход открыт всем**, у кого есть ссылка на бота.
- Токен бота (`BOT_TOKEN`) в том же файле никому не показывайте.
- У каждого пользователя свои программы и тренировки — друг друга они не видят.
- Если что-то пошло не так, лог приложения: `docker compose logs --tail 50 app`.
